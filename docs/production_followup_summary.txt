   indicator. It uses HICN, provider and admission date by default. All 914

   records (190 single copies and 362 CY/FY pairs).

- Split: transaction values outside 0..4 belong to the exception output. Selected
  inputs also repeat configured claim identities. Row evidence gives original
  locations; duplicates are not silently deleted.

  discrepancy (for example calculated Y30109 versus supplied Y20109). The run

  business cycles. Use an approved matching archive business date/extraction
  when comparing historical outputs; the framework does not change it silently.

  care-end rule. Missing is not assumed to mean an explicitly empty collection.
  Some supplied aggregate outputs also differ in codes/amounts. This run selects
  at most five rows per input file; a full-reference Stay may aggregate additional
  unselected bills. Sample results do not certify those full groups.
- Intermediate: supplied records contain procedure dates outside the selected
  business-date window. Forwarded groups also encounter missing birth dates
  and/or out-of-window discharge dates. The exact source values and allowed
  window appear in the row evidence. An approved beneficiary reference or
  matching historical business date is required as appropriate.
- Whole-population original/KEEP/DROP balances may differ because supplied paths
  contain repeated identities/extractions. Every file remains counted once by
  path. The population audit retains fingerprints, multiplicities and locations;
  no extraction is selected or discarded automatically to make totals match.
